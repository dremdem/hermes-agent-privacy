Privacy policy — Hermes Agent

Last updated: 13 October 2026

Who this covers

Hermes Agent is a personal assistant running on its author's own computer. The author is its only user and owns the Google account it connects to. It is not offered to anyone else, and no other person's data is processed.

What access it uses

  • Gmail — read: searching and reading the owner's own mail.
  • Gmail — send: sending and replying from the owner's address, on his explicit instruction.
  • Gmail — modify: labels and read/unread state. Deleting mail is not permitted — that scope was not requested.
  • Calendar: reading events and creating or changing them.

No access to Google Drive, Docs, Sheets or Contacts is requested.

Where the data goes

Mail and calendar data are fetched on demand and kept on the owner's own machine — there is no server and no cloud storage belonging to this application.

The assistant answers using a large language model. To produce an answer, the part of a message the task needs is sent to the model provider the owner has configured (currently OpenAI, through his own paid account) and is handled under that provider's terms. No other third party receives this data.

Google user data is never sold, never used for advertising, and never used to train generalized AI or machine-learning models by the author.

Removing access and data

  • Revoke the application's access at myaccount.google.com/permissions.
  • Deleting the local token file removes the stored credential; deleting the application's data directory removes everything it kept locally.
