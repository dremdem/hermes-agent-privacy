# hermes-agent-privacy

Home page and privacy policy for **Hermes Agent**, a personal assistant that
runs on its owner's own computer. Published here because Google requires a
public home page and privacy policy before an OAuth app can leave *Testing*
mode — where refresh tokens expire after about a week.

No code and no data live here: two static pages, served by GitHub Pages.

- https://dremdem.github.io/hermes-agent-privacy/
- https://dremdem.github.io/hermes-agent-privacy/privacy.html
